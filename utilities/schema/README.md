# Schema Service

Manage the mixins schemas for miscellaneous types.

### Key features and benefits

* Uploads JSON files to create schemas for objects like availability, cart, cart_item, category, company, coupon, customer, customer_address, custom_entity, location, media, order, order_entry, price_list, product, quote, return, site, and vendor
* Supports mixin localization
* Allows easy and quick creation of custom mixins
* Supports the following field types: Array, Boolean, Date, Date Time, Decimal, Enum, Number, Object, Text and Time
